multiberry

Ansible playbooks for a CachyOS gaming and local AI machine with an NVIDIA GTX 1080.

Repository Playbooks

Hardware

Machinemultiberry
CPUAMD Ryzen 7 3700X (8 cores / 16 threads)
Memory32 GB DDR4-3200
GraphicsNVIDIA GeForce GTX 1080 (Pascal, 8 GB)
SystemCachyOS, Limine

What it sets up

  • Base: keyrings, upgrade, users and groups, extra drives, kernel options, Neovim as editor
  • Graphics: legacy NVIDIA 580xx driver stack for Pascal, Wayland stability, game tuning
  • Gaming: Steam, Microsoft Flight Simulator 2024 through Proton, Firestorm viewer, wlsunset
  • Local AI: Ollama built as a package, model management, Open WebUI, agents in Docker
  • Desktop: Flatpak, Google Chrome, Docker

Every setup playbook has a teardown.

Usage

./ansible-user-setup.yml -K     # create the ansible user (needs your sudo password)
./setup.yml                     # run every setup playbook
./teardown.yml                  # revert it
